# Play Mode scenario life cycle

## Active Scenario Window

The Active Scenario window displays the status and controls for all instances in your scenario. You can manage instance execution, check status information, and access debugging tools from this window. For more details on configuration options, refer to the [Scenario configurations page](play-mode-scenario-configurations.md).

### Open the Active Scenario window

To open the Active Scenario window:

1. Navigate to **Window** > **Play Mode** > **Active Scenario**.

Alternatively, while in Play Mode:

1. Expand the Play Mode status dropdown.
2. Select the status window icon.

### What you can do in the Active Scenario window

The Active Scenario window allows you to:

* View instance status, port, address, and error information
* Activate and deactivate Editor instances
* Control the Keep Active setting for Editor instances.
* Toggle between Scenario control and Manual control modes.
* Focus on specific Editor instance windows.
* Refresh the Virtual Project folder to clear Editor instance library folders.
* Launch local instances independently when in Manual control mode.

For a complete list of all controls and properties, refer to the [Active Scenario window reference](../mppm-reference/play-mode-status-window-reference.md).
